Weapon Management System

Project Description

The Weapon Management System is a web-based application developed to manage weapon records and related information efficiently.

Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

Project Structure

- backend/ – Flask backend application
- frontend/ – User interface
- .gitignore – Files excluded from Git tracking

Features

- Weapon record management
- Database connectivity using MySQL
- Backend API using Flask
- User-friendly web interface

How to Run

1. Install the required Python packages.
2. Configure MySQL database credentials in the ".env" file.
3. Start the Flask backend.
4. Open the frontend in your browser.
